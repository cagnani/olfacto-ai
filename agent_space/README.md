# Olfacto Sommelier

Descrições sensoriais para menus, a partir de aromas previstos pelo modelo de odor
molecular. O LLM recebe a lista de aromas prevista e apenas redige o texto — não inventa
aromas.

- Modelo: [SamuelCagnani/olfacto-chemberta-138](https://huggingface.co/SamuelCagnani/olfacto-chemberta-138)
- Dataset: [SamuelCagnani/olfacto-odor-138-ptbr](https://huggingface.co/datasets/SamuelCagnani/olfacto-odor-138-ptbr)
- Código: [github.com/cagnani/olfacto-ai](https://github.com/cagnani/olfacto-ai)
- Artigo do agente: [PT-BR](https://github.com/cagnani/olfacto-ai/blob/main/docs/hf-blog-agent-ptbr.md) · [EN](https://github.com/cagnani/olfacto-ai/blob/main/docs/hf-blog-agent-en.md)
Artigo do modelo: [PT-BR no Hugging Face](https://huggingface.co/blog/SamuelCagnani/olfacto-ai-br)

Protótipo de pesquisa. Não faz alegações de alérgenos, saúde ou segurança alimentar.
