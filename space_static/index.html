Como funciona

O modelo recebe um SMILES — a representação textual da molécula — e retorna a probabilidade de 138 descritores. O ensemble combina um ChemBERTa fine-tunado com um baseline de fingerprints Morgan + regressão logística. O peso de 80% para o fingerprint foi escolhido por validação out-of-fold.

from olfacto.ensemble import EnsemblePredictor

predictor = EnsemblePredictor.from_pretrained(
    "SamuelCagnani/olfacto-chemberta-138",
    "data/odor_labels_ptbr.json",
    "fingerprint.joblib",
)
for p in predictor.predict("CCO", top_k=5):
    print(p.label_pt_br, round(p.probability, 3))

Limitações: prevê qualidade olfativa, não intensidade; apenas moléculas únicas, não misturas; rótulos de catálogo têm ruído e viés para fragrâncias comerciais. Esta é uma demo estática com previsões pré-computadas — o app Gradio completo está no GitHub.
